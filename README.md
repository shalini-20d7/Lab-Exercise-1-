a) Explore the Fundamentals of UI and UX 
UI – User Interface 
    UI refers to the visual and interactive elements of a digital product. 
Examples: 
  ● Buttons 
  ● Icons 
  ● Colors 
  ● Typography 
  ● Images 
  ● Navigation bars 
UX – User Experience 
       UX refers to the overall experience a user has while using a product or application. 
UX focuses on: 
 ● Ease of use 
 ● User needs 
 ● User satisfaction 
 ● Accessibility

Basic UI/UX Principles 
1. Consistency – Maintain similar styles throughout the application. 
2. Visual Hierarchy – Important information should be more noticeable. 
3. Contrast – Use differences in color, size, and weight for visibility. 
4. Alignment – Properly align elements to create a clean layout. 
5. Spacing – Provide sufficient space between elements. 
6. Typography – Use readable and suitable fonts. 
7. Color – Use an appropriate and consistent color palette. 
8. Feedback – The system should respond to user actions. 
9. Accessibility – Design should be usable by different types of users. 
10. Simplicity – Avoid unnecessary elements and complexity.

UX 
Deals with overall experience

Case Study: Amazon 
UI: 
  ● Product images 
  ● Search bar 
  ● Add to Cart button 
  ● Product cards 
  ● Navigation menu 
  ● Colors and typography 
UX: 
  ● Easy product search 
  ● Product filtering 
  ● Product comparison 
  ● Simple checkout 
  ● Order tracking 
  ● Personalized recommendations

Amazon needs both a good UI and good UX. Attractive product pages represent UI, while the

c) Illustrate the Relationship Between UI and UX

UI and UX are closely connected.

USER NEEDS 
↓ 
UX RESEARCH 
↓ 
UX DESIGN 
(Flow & Structure) 
↓ 
UI DESIGN 
(Colors, Fonts, Buttons) 
↓ 
INTERACTION 
↓ 
USER SATISFACTION

UX determines how the product works through structure and user flow, while UI determines how 
it looks and interacts by presenting that structure visually. Together, they create a usable, 
attractive, and satisfying product. 
Example: 
In an online shopping application, UX decides how the user searches for a product, views 
details, adds it to the cart, and completes payment. UI designs the search bar, product cards, 
buttons, cart icon, and payment screens.
